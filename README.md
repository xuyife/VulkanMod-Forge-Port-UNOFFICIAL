# VulkanMod Forge Port (Unofficial)

[![License: LGPL v3](https://img.shields.io/badge/License-LGPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Minecraft](https://img.shields.io/badge/Minecraft-Java_Edition-green.svg)](https://minecraft.net)

**VulkanMod Forge Port (Unofficial)** is an unofficial port of [VulkanMod](https://github.com/xCollateral/VulkanMod) to Minecraft (Neo)Forge. This mod replaces the vanilla OpenGL renderer with Vulkan API for better performance and modern rendering features.

---

## ✨ Features

- Reduced CPU and GPU Overhead
- Terrain rendering optimizations, ranging from optimized draw loop to section culling
- Chunk building optimizations
- Entity rendering optimizations
- Native Wayland support (Linux specific)
- Windowed fullscreen mode

---

## 📋 Requirements

- Minecraft Java Edition
- Minecraft (Neo)Forge (latest recommended)
- Java 17 or higher
- Windows / Linux / macOS
- GPU with Vulkan 1.2+ support

---

## 🚀 Installation

1. Install Minecraft (Neo)Forge for your Minecraft version
2. Download the latest JAR file from [Releases](https://github.com/xuyife/VulkanMod-Forge-Port-UNOFFICIAL/releases)
3. Place the JAR into `.minecraft/mods/`
4. Launch the game with the (Neo)Forge profile
